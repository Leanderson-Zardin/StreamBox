# StreamBox

Projeto educacional para aprendizado de desenvolvimento web e engenharia de software.

## Objetivo

Construir uma aplicação completa de catálogo de filmes e séries,
evoluindo gradualmente do frontend até backend, banco de dados,
autenticação, testes e deploy.

## Stack atual

- HTML
- JavaScript Vanilla
- Tailwind CSS

## Stack futura

- Node.js
- Express
- PostgreSQL

## Regras de desenvolvimento

- Não utilizar React.
- Não utilizar TypeScript.
- Priorizar JavaScript Vanilla.
- Não adicionar frameworks ou bibliotecas sem necessidade.
- Priorizar código simples e didático.
- Evitar abstrações prematuras.
- Não implementar funcionalidades além da tarefa solicitada.
- Explicar mudanças estruturais importantes.
- Manter responsabilidades dos arquivos claras.

## Objetivo educacional

O código pode ser gerado com auxílio de IA, mas a estrutura deve
permanecer compreensível para alguém estudando desenvolvimento web.

Sempre priorizar clareza em vez de soluções excessivamente sofisticadas.
